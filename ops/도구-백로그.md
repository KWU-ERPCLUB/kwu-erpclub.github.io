# 도구 백로그 — 도감 카드 재고 목록

> 용도 = 성격 「도구·활용」 카드의 **공급 재고**. 트렌드·심층이 신호 구동(사건이 와야 씀)인 것과 달리, 도감은 재고 구동이다 — 오래된 도구도 유효하므로 신선도 스윕으로는 영구히 안 잡힌다.
> 배경 = 2026-08-25 오너 판정: 성격 4값 중 활용법·튜토리얼 0건·도구·프롬프트 1건(실측 28편) → 죽은 필터 칩 2개. 원인·결정 = spec `docs/specs/2026-08-25-도구도감-트랙.md`.
> 쓰는 쪽 = **야간 인사이트 루틴의 금요일 칸**. 상태 '대기' 1건을 골라 카드 5절로 작성하고, 게재 후 이 표의 상태를 갱신한다.
> 규칙 = 행 추가·갱신만(삭제 금지 — 기각도 상태로 남긴다). 상태 enum = { 대기 | 작성중 | 게재 | 기각 }. 게재 시 기사 파일명을 메모에 적는다.
> 등재 관문 = "MIS·기획 직군이 알아두면 이득인가" = T. 개발 전용 도구라도 **그 직군이 협업·발주·판단에 쓰는** 이득이 있으면 통과.

## 카드 규격 (요약 — 원천 = `../CONTRIBUTING.md` 「도감 5절」)

① 이게 뭔가(비유 1개) → ② 누가 왜 쓰나 → ③ 시작하는 법(따라 하면 재현) → ④ 주의할 점 → ⑤ 더 볼 곳(공식 문서)

**가격·모델명·사용 제한 수치는 카드에 쓰지 않는다** — 변동값은 ⑤ 공식 링크로 보낸다(부패 방지, 오너 2026-08-25).

## 운영 규칙 (if-then)

- `금요일 05:00 KST → 상태 '대기' 최상단 1건 선택 → 상태 '작성중' → 카드 작성 → 게재 후 '게재' + 파일명 메모`
- `'대기' 0건 ∧ 스윕 신규 등재 0건 → 그 금요일 발행 생략`(수량 채우기 승격 금지)
- `야간 스윕에서 새 도구 발견 ∧ 등재 관문 T → 표 하단에 '대기'로 등재`
- `등재 관문 F로 판정 → 상태 '기각' + 사유 메모`(행 삭제 금지)
- `도구가 단종·개명됨을 확인 → 해당 카드 갱신 또는 revert 커밋, 사유는 커밋 메시지에`
- `도감 카드 게재 → 개념 레이더 상태는 바꾸지 않는다`(레이더 = 심층 후보 추적, 도감 = 사용법. 둘은 별개 축)

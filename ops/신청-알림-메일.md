## 1. Apps Script 웹앱 (오너 1회, 3분)

1. https://script.google.com → 새 프로젝트 → 이름 `aim-신청-알림`
2. `Code.gs` 내용을 아래 스크립트로 교체. `SECRET` 값은 아무 문자열이나 길게(예: 20자) 정해서 바꾼다.
3. 배포 → 새 배포 → 유형 **웹 앱** → 실행 주체 **나** → 액세스 권한 **모든 사용자** → 배포 → 권한 승인(Gmail 발송) → **웹 앱 URL 복사**

```javascript
// aim-신청-알림 — Supabase applications INSERT 웹훅을 받아 메일로 보낸다.
const TO = 'win737449@gmail.com';
const SECRET = 'CHANGE-ME-20-CHARS';          // Supabase 웹훅 URL의 ?k= 값과 같아야 한다

function doPost(e) {
  const key = (e && e.parameter && e.parameter.k) || '';
  if (key !== SECRET) return ContentService.createTextOutput('forbidden').setMimeType(ContentService.MimeType.TEXT);

  let body = {};
  try { body = JSON.parse(e.postData.contents || '{}'); } catch (err) { body = {}; }
  if (body.type !== 'INSERT' || body.table !== 'applications' || !body.record) {
    return ContentService.createTextOutput('ignored').setMimeType(ContentService.MimeType.TEXT);
  }

  const r = body.record;
  const when = Utilities.formatDate(new Date(r.created_at || Date.now()), 'Asia/Seoul', 'yyyy-MM-dd HH:mm');
  const subject = `[AIM 신청] ${r['이름']} · ${r['전공']} · ${r['학번']}`;
  const text = [
    `제출 시각: ${when} (KST)`,
    ``,
    `이름: ${r['이름']}`,
    `학번: ${r['학번']}`,
    `전공: ${r['전공']}`,
    `전화번호: ${r['전화번호']}`,
    ``,
    `써본 AI: ${r['써본ai'] || '-'}`,
    `관심 주제: ${r['관심주제'] || '-'}`,
    `지원 계기: ${r['지원계기'] || '-'}`,
    ``,
    `전체 목록: https://kwu-erpclub.github.io/workspace/?tab=운영 → 지원자`,
  ].join('\n');

  MailApp.sendEmail({ to: TO, subject: subject, body: text, name: 'AIM 신청 알림' });
  return ContentService.createTextOutput('ok').setMimeType(ContentService.MimeType.TEXT);
}

// 테스트용: 편집기에서 이 함수를 실행하면 샘플 메일이 간다(권한 승인도 여기서).
function testMail() {
  MailApp.sendEmail({ to: TO, subject: '[AIM 신청] 테스트', body: '웹앱 연결 전 발송 테스트', name: 'AIM 신청 알림' });
}
```

- 컬럼 = 이름·학번·전공·전화번호·써본ai·관심주제·지원계기(0017)·created_at. 폼이 바뀌어 컬럼이 늘면 위 목록에 한 줄 추가.
- 하루 발송 한도(개인 Gmail 계정 Apps Script) = 100통. 모집 규모에서 충분하다.

## 2. Supabase 웹훅 (오너 1회, 2분)

1. https://supabase.com/dashboard → 프로젝트 `erpclub-hub` → **Database → Webhooks → Create a new hook**
2. 값:
   - Name `applications-mail`
   - Table `applications` · Events **Insert**만
   - Type **HTTP Request** · Method **POST**
   - URL = 1단계 웹 앱 URL 뒤에 `?k=SECRET값` 붙여서 (예 `https://script.google.com/macros/s/AKfy.../exec?k=abcd...`)
   - HTTP Headers: 기본값(Content-type: application/json) 유지
3. 저장 → `/recruit` 폼에서 테스트 제출 1건 → 메일 도착 확인 → 테스트 행은 지원자 목록에 남으니 이름에 "테스트"라고 적는다

참고: 폼 학번은 **숫자 10자리** 엄격(예 2026000000). Apps Script `/exec`는 POST에 302로 응답하지만 `doPost`는 그 전에 실행되므로 pg_net이 리다이렉트를 안 따라가도 메일은 간다(실행 기록에서 확인).

## 3. 확인·장애

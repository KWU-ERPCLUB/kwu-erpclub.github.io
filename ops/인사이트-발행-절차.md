# 인사이트 발행 절차 — 심층 (AI 프롬프트 겸 사람 절차) — 2026-09-12 개편판

> 이 문서 = 단건 심층 기사 발행의 **운영 원천**. 자동 루틴이 죽거나 계정이 바뀌어도 이 문서로 재구축·수동 실행이 된다.
> 사용법 ① AI에게: 이 문서 전체를 붙여 넣고 "이 절차대로 오늘 치 심층 발행". ② 사람이: §6.
> 개편(2026-09-11~12 오너, spec = `erp-club/docs/specs/2026-09-11-인사이트-개편.md`): **심층 선정에 사람 판단을 두지 않는다.** 주간 보고의 후보 표 T/F와 6칸 게이트가 고른다. 못 채우면 안 쓴다(0편이 기본값).
> frontmatter 규격·이미지 규칙 = `../CONTRIBUTING.md` / 검수 = `기사-검수-하네스.md` §4.

## §0 독자·정의

- **주 독자 = AIM 스터디원**(광운대 경영학부 중심, AI에 관심 있는 비개발자, 취업 준비 국면).
- **심층 = 주간이 "무슨 일"을 알려 줬다면, 심층은 주간이 답 못 한 질문에 팩트로 답하고 독자가 가져갈 인사이트를 준다.** 행동 지시 절은 두지 않는다(오너). 주간 TOP 본문 문장을 재사용하지 않는다.
- 공식 발표·투자·M&A·실적 자체는 심층 소재가 아니다(주간 "그 외 한 줄" 몫).

## §1 발행 체계

| 경로 | 실행 | 소재 |
|---|---|---|
| 자동(야간 루틴) | **화·수·목 05:00 KST**, 회차당 최대 1편 | 직전 주간 보고 frontmatter `심층후보` 중 ⓪~⑥ 전부 T · 미발행 · 순위 1위 |
| 수동(요청) | 스터디원 요청 시 | `후보출처: 요청`. 6칸 게이트는 동일 적용 |

- 주 최대 3편(슬롯 3). 후보가 없거나 게이트를 못 채우면 그 회차는 **발행 없이 종료**한다. 억지로 채우지 않는다.
- 순위 = ③ 증거 링크 수 → 국내 여부 → 최신.
- **구조적 잠금**: frontmatter `후보출처: weekly-trend-wNN#k`. `npm run validate`가 그 주간 파일의 `심층후보` k행이 존재하고 ⓪~⑥ 전부 T인지 검사한다. 후보 표 밖 소재로 쓴 심층은 빌드가 막는다.
- 개념 레이더(`개념-레이더.md`)의 개념도 주간 후보 표를 거쳐야 심층이 된다(경로 1개).

## §2 6칸 게이트 (전부 채워야 발행 — 검증기가 헤딩·행 수·분량 검사)

| 칸 | 담는 것 | 최소 근거 |
|---|---|---|
| `::: 질문` | 이 글이 답하는 질문 **정확히 3줄**. 주간 TOP에 없던 것 | — |
| `## 무슨 일` | 사실 요약 4문장 이내 | 원문 1 |
| `## 실물 …` | 형식·문항·수치·절차 등 "안에 뭐가 있나". **공개된 것과 아직 안 나온 것을 표로 구분** | 원문 인용 2 |
| `## 앞선 사례 …` | 이미 겪은 사람·회사의 후기·사례(개인 경험 표기). 없으면 "없다"와 그 이유(첫 도입 등)를 쓴다 | 후기·사례 2 |
| `## 판정 기준 …` | 담당자·현업·공식 가이드가 말한 "무엇을 보는가". 감점 기준이 문서로 있으면 인용 | 발언 원문 1 |
| `## 확인 안 된 것` | 모르는 것을 모른다고 적는 표 | 1행 이상 |
| `## SO WHAT …` | 우리가 가져갈 인사이트 3항(굵은 첫 문장 + 근거 1~2문장). 낙관 착지 금지 | — |
| `::: 출처` | `이름 | URL` 5건 이상 | 5 |

- 분량 = **1,800~3,000자**(공백·링크·출처 제외). 문단 ≤ 2문장 · 문장 ≤ 50자 · 두괄식(절 첫 문장 = 결론) · 표 ≤ 2 · 문단 안 볼드 ≤ 1 · 용어는 첫 등장에 괄호 풀이 · **대시(—) 금지**(제목·본문. 출처 블록만 예외) · 기사 상호참조 금지.
- 톤 = 「AI 티 지우기」 6규칙(번역투·대명사 직역·반복 대구·관계절 과잉·완곡 겹치기·상투적 결론 금지) + 실무 용어 짧게.
- **이미지 필수**: 소재의 실제 이미지(원문 키비주얼·공식 화면·보도 실사) 1200×750 JPEG → `public/img/covers/` + SOURCES.md 1줄 + `이미지`·`이미지설명`. 무관한 스톡·로고 금지. **못 구하면 발행 보류**(억지 이미지 금지).

**D 데이터**: 조사 기관 원문(원티드랩·고용정보원 등) · 벤치마크

## §4 절차 (순서 고정)

1. **후보 확인**: 직전 주간 보고(`weekly-trend-wNN`) frontmatter `심층후보`에서 ⓪~⑥ 전부 T이고 아직 심층이 없는 행을 순위대로 고른다. 없으면 종료.
2. **조사**: §2의 칸을 하나씩 채울 근거를 모은다(원문 인용·후기·발언). 링크는 접속 확인. 한 칸이라도 근거가 없으면 **그 소재를 버리고 다음 후보**로. 모두 없으면 종료.
3. **작성**: `../app/content/기사/YYYY-MM-DD-<작성자>-<슬러그>.md`. frontmatter = `성격: 심층 분석` · `축`(후보 행과 동일) · `후보출처` · `이미지`·`이미지설명` · `설명`(1줄) · `태그`(1~5). 본문 순서 = `::: 요약`(3줄 + 나한테 왜) → `::: 질문` → `## 무슨 일` → `## 실물 …` → `## 앞선 사례 …` → `## 판정 기준 …` → `## 확인 안 된 것` → `## SO WHAT …` → `::: 출처`.
4. **자검**: `기사-검수-하네스.md` §4 전항 T.
5. **게이트·게재**: `cd app` → `npm run validate`(6칸·분량·후보출처 잠금·이미지·대시) · `npm test` · `npm run build` → main commit·push. 게이트 실패 = 게재 금지, 사유 보고.
6. **레이더 갱신**: 담론형 소재를 게재·기각했으면 `개념-레이더.md` 상태 갱신.

## §5 서식 함정

| 함정 | 규칙 |
|---|---|
| 볼드 뒤 한글 | `**79%**다` 파싱 실패 → `**79%다**` 또는 문장 재배치 |
| 대시 | 제목·본문 금지(검증기). 절 제목 부제는 `## 실물 해부: 부제`처럼 콜론 |
| 표 폭 | 열 ≤ 3(375폭 가독) |
| 물결 기간 | `~` 대신 `–` |

## §6 사람 폴백 (AI 없이)

1. 최근 주간 보고의 `심층후보`에서 전부 T인 행을 고른다(없으면 이번 주는 심층 없음).
2. §2 표를 위에서부터 채운다. 못 채우는 칸이 생기면 멈춘다.
3. 최근 심층 1건을 열어 같은 서식으로 쓴다. 이미지는 원문 페이지의 대표 이미지를 1200×750으로.
4. GitHub 웹 commit → Actions 초록 확인. 빨간불이면 오류 문구(칸 결측·분량·대시)를 보고 고친다.

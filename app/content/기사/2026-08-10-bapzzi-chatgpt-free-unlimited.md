::: 요약
- 8월 6일 OpenAI 발표 — 무료(Free)·Go 사용자의 **텍스트 대화 횟수 제한을** 없앤다. 기본 모델도 GPT-5.6 Luna로 교체된다.
- 무제한은 텍스트 한정이다. 파일 업로드·이미지·음성·이미지 생성 제한은 그대로 남는다.
- 열리는 것은 3단 모델 티어의 **최하단이다.** 상단 모델과의 격차는 이번 발표로 좁혀지지 않는다.
:::

## 무엇이 바뀌나

OpenAI가 8월 6일 ChatGPT 무료·Go 요금제의 변경을 발표했다. 핵심은 두 가지다 — 기본 모델 교체와 텍스트 대화 횟수 제한 폐지.

TechCrunch는 그동안 무료·Go 사용자가 대화 도중 한도에 걸려 유료 전환 안내를 받는 구조였다고 전했다. 그 벽이 텍스트 대화에서 사라진다.

| 항목 | 이전 | 이번 변경 |
|---|---|---|
| Free·Go 기본 모델 | GPT-5.5 | **GPT-5.6 Luna** |
| 텍스트 대화 횟수 | 상한 있음 — 도달 시 유료 안내 | **무제한** |
| 추론 강화 | 무료엔 없음 | **Think 버튼** 추가 |
| 파일·이미지·음성·이미지 생성 | 제한 | 제한 유지 |
| Plus·Pro 기본 모델 | 기존 Sol | 개선판 GPT-5.6 Sol |

적용 시점은 두 단계로 나뉜다. 기본 모델 교체는 발표 당주(8월 3일 주)에, 텍스트 무제한과 Think 버튼은 **8월 10일 주부터** 순차 적용된다.

Think 버튼¹은 어려운 질문에 추론을 더 쓰게 하는 선택지다. 무료 사용자가 이 모드를 몇 번까지 쓸 수 있는지는 발표에 없다.

::: 용어
Think 버튼 | 답을 바로 내지 않고 더 오래 따져 보게 하는 모드. 정답이 하나로 정해진 계산·논리 문제에서 차이가 크다
:::

## 왜 지금인가 — 앞서 놓인 세 가지 사실

무제한 개방은 갑자기 나온 결정이 아니다. 그 앞에 놓인 사실 세 가지를 순서대로 본다.

**첫째, 최하단 모델의 원가가 내려갔다.** 7월 30일 OpenAI는 Luna의 API 단가를 100만 토큰당 입력 $1·출력 $6에서 **$0.20·$1.20으로** 내렸다(CNBC). 인하폭 80%다.

같은 대화량을 감당하는 비용이 5분의 1이 됐다는 뜻이다. 무제한을 켤 수 있는 원가 조건이 발표 일주일 전에 먼저 갖춰졌다.

**둘째, 무료 티어가 수익이 나는 자리로 바뀌었다.** OpenAI는 2월 9일부터 Free·Go 요금제에 광고를 붙였다(Axios). 광고 모델에서는 사용량 자체가 매출의 재료가 된다.

**셋째, 규모가 이미 크다.** OpenAI는 2월 27일 ChatGPT 주간 활성 사용자 **9억 명을** 공개했다(Search Engine Land 보도, OpenAI 발표 인용).

세 사실은 같은 방향을 가리킨다 — 대화량을 늘리는 쪽이 손해가 아닌 구조. 다만 OpenAI가 광고를 이유로 무제한을 켰다고 공식 설명한 바는 없다. 여기까지는 공개된 사실의 배열이고, 인과는 확인되지 않았다.

## 개념 — 티어와 '무제한'의 단위

이번 건을 읽으려면 두 가지 구분이 필요하다.

**모델 티어는** 같은 세대 안에서 성능과 값이 다른 등급이다. GPT-5.6은 Luna·Terra·Sol 3단이고, 무료에 열리는 것은 최하단인 Luna다.

무료 사용자가 더 많이 쓰게 되는 모델과, 유료 사용자가 쓰는 모델은 여전히 다른 물건이다. 횟수 제한이 풀린 것이지 등급이 올라간 것이 아니다.

**'무제한'의 단위도** 좁다. 이번에 풀린 것은 텍스트 대화뿐이고, 파일 업로드·이미지·음성·이미지 생성에는 별도 제한이 남는다고 OpenAI가 명시했다.

즉 문서를 올려 분석시키거나 이미지를 만드는 작업은 이번 변경의 바깥이다. 실제 과제에서 병목이 되는 쪽은 대개 이 바깥이다.

## 연관 흐름 — 값이 아니라 자리를 두고 겨룬다

최하단 구간의 값은 계속 눌리고 있다. DeepSeek는 7월 31일 V4-Flash를 정식 공개했고, MIT 라이선스로 상업 이용까지 열었다(Caixin Global).

저가 구간에서 값으로 차별화하기 어려워지면, 경쟁은 값이 아니라 *사용자가 머무는 자리*로 옮겨 간다. 무료 무제한은 그 자리를 넓히는 수단에 가깝다.

한 가지 더 짚을 것은 데이터다. 무료 티어는 광고가 붙는 구간이고, 광고 기반 서비스에서 대화 기록은 통상 타깃팅 재료가 된다. 유료 구간과 같은 조건이라고 가정할 근거는 없다.

## SO WHAT

**닿는 경로·시차.** 이 변경은 계정 단위로 배포되므로 한국 사용자에게도 8월 10일 주 안에 닿는다. 규제 관문이나 국내 총판을 거치지 않는다.

반대로 취업 후에는 오히려 멀어진다. 국내 기업·기관에서는 무료 계정으로 외부 AI에 사내 문서를 넣는 행위 자체가 막히는 경우가 많다 — 금융권 망분리, 공공 CSAP 조달 요건, 대기업 사내 반출 통제가 그 축이다.

그래서 이 무제한이 가장 크게 닿는 시점은 지금, 학생 신분일 때다.

**지금 해당 없는 것.** 무제한은 최상위 모델 무제한이 아니다. 열린 것은 Luna이고, Plus·Pro의 Sol과는 다른 등급이다.

파일 업로드·이미지·음성 제한은 남는다. 과제에서 PDF를 통째로 넣어 돌리는 용도라면 이번 발표로 달라지는 것이 없다.

Think 버튼도 사용 횟수 조건이 공개되지 않았다. "무료로 추론 모델을 무제한으로 쓴다"는 해석은 아직 근거가 없다.

**지금 할 수 있는 것.**

- 반복 과제(요약·분류·번역) 3건을 무료 계정에서 실제로 돌리고, **Luna가 무너지는 지점을** 기록한다. 어떤 작업에서 답이 틀리기 시작하는지가 티어 선택의 기준이 된다.
- 같은 프롬프트를 Think 켠 상태와 끈 상태로 각 1회 돌려 비교한다. 추론 모드가 값을 하는 작업 유형은 생각보다 좁다.
- 설정에서 데이터 사용·개인화 옵션을 열어 현재 값을 확인한다. 학번·주민번호·이력서 원본을 대화창에 넣지 않는 선은 무제한과 무관하게 유지한다.

횟수 제한이 사라진다고 쓸 수 있는 작업의 범위가 넓어지지는 않는다. 넓어지는 것은 같은 작업을 반복할 여유이고, 그 여유를 어디에 쓰는지는 사용자가 정한다.

본문 규격(2026-09-12 확정 — 검증기가 검사한다):
- 심층 = **1,800~3,000자**(공백·링크·출처 제외) · 주간 ≤ 2,500자. 문단 ≤ 2문장 · 문장 ≤ 50자 · 용어는 첫 등장에 괄호 풀이 · **대시(—) 금지**(제목·본문).
- 심층 필수 구조 = `::: 요약`(30초 요약 3줄 + 나한테 왜) → `::: 질문`(이 글이 답하는 질문 정확히 3줄, 주간이 답 못 한 것) →
  `## 무슨 일` → `## 실물 …`(형식·문항·수치·절차, 원문 인용 2+, 공개된 것/안 나온 것 구분) → `## 앞선 사례 …`(후기·사례 2+, 개인 경험 표기)
  → `## 판정 기준 …`(담당자·현업 발언 원문 1+) → `## 확인 안 된 것`(표) → `## SO WHAT …`(우리가 가져갈 인사이트 3항) → `::: 출처`(5건 이상).
  한 칸이라도 근거로 못 채우면 그 주 심층은 쓰지 않는다.
- 주간 = `::: 요약` → `## 이번 주 TOP 3`(`::: 탑` 카드 3) → `## 이번 주 브리핑`(`### 축` + `::: 브리핑` 카드, 항목 2~3문장) → `### 그 외 한 줄`(≤5) → `::: 출처`. 심층 후보 표는 frontmatter `심층후보`에.

- 이미지: `![대체텍스트](이미지-URL)` — 본문 폭(640px)에 맞춰 자동 축소.
- 링크: `[표시 문구](https://...)`.
- 강조·목록·인용(콜아웃) 등 마크다운 문법 사용 가능.

주석(`#`·`<!-- -->`) 줄은 저장 전 삭제. 규칙 = `src/content/schema.js`(단일 원천).
이미지 관련성 기준·라이브러리 위치·SOURCES 기록 = repo 루트 `CONTRIBUTING.md` 「이미지·이미지설명」 절.

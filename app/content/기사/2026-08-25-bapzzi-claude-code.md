## 이게 뭔가

클로드 코드는 터미널에서 도는 AI다. 대화창에서 답을 받아 내가 옮겨 적는 방식이 아니라, 내 컴퓨터의 파일을 직접 열어 읽고 고친다.

비유하면 이렇다. 채팅형 AI가 전화로 알려주는 상담원이라면, 클로드 코드는 내 책상에 앉아 서류를 직접 만지는 조수다.

공식 문서는 "코드베이스를 읽고, 파일을 편집하고, 명령을 실행하는 에이전틱 코딩 도구"로 설명한다. 여기서 에이전틱은 사람이 단계마다 지시하지 않아도 여러 단계를 스스로 이어서 처리한다는 뜻이다.

터미널 말고도 웹·데스크톱 앱·VS Code·JetBrains에서 쓸 수 있다.

## 누가 왜 쓰나

이름에 코드가 들어가지만 쓰임은 파일 다루기 전반이다. 폴더에 흩어진 문서를 규칙에 맞게 정리하거나, 여러 파일에 걸친 표기를 한 번에 맞추는 일에 쓴다는 실사용 기록이 늘고 있다.

기획 직군에게 실익이 나는 지점은 두 곳이다. 첫째, 결과물이 대화창이 아니라 파일로 남는다. 둘째, 무엇을 고쳤는지 변경 이력으로 확인할 수 있다.

반대로 한 번 묻고 한 번 답받는 용도라면 굳이 이걸 쓸 이유가 없다. 일반 채팅형 AI가 더 빠르다.

## 시작하는 법

설치는 명령 한 줄이다. 윈도우 PowerShell에서는 다음을 붙여 넣는다.

```
irm https://claude.ai/install.ps1 | iex
```

맥과 리눅스는 이쪽이다.

```
curl -fsSL https://claude.ai/install.sh | bash
```

설치가 됐는지 확인한다. 버전 번호 뒤에 `(Claude Code)`가 찍히면 성공이다.

```
claude --version
```

이제 작업할 폴더로 이동해 실행한다. 처음 실행하면 브라우저가 열리며 로그인을 요구한다.

```
claude
```

첫 질문은 무겁지 않은 것으로 시작한다. 파일을 읽고 요약하는 일이라 위험이 없다.

```
이 폴더에 뭐가 들어 있는지 설명해줘
```

## 주의할 점

계정이 필요하다. Claude 구독 또는 Console 계정, 혹은 회사가 쓰는 클라우드 제공자를 통해 로그인해야 열린다.

파일을 실제로 고친다는 점이 장점이자 위험이다. 변경 이력을 남기지 않는 폴더에서 쓰면 되돌리기가 어렵다. 처음에는 git으로 이력이 남는 폴더에서 시작하는 편이 안전하다.

승인 방식도 알아둘 값어치가 있다. 설치 후 첫 세션은 변경마다 사람에게 묻지만, 이후에는 플랜에 따라 대부분의 작업을 묻지 않고 진행하는 모드로 시작한다. 세션 중 `Shift+Tab`으로 이 모드를 바꿀 수 있다.

터미널을 한 번도 써본 적이 없다면 진입 문턱이 있다. 공식 문서가 터미널 안내서를 따로 두고 있으니 그쪽을 먼저 본다.

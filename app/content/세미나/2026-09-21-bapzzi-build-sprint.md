차시 2에서 확정한 자기 소재를 실제로 돌리는 회차. 설명을 듣는 시간이 아니라 각자 만드는 시간이다. 미니 PRD 5칸을 위임문으로 바꿔 챗봇(아무거나)에 넣고, 나온 결과를 내 원자료와 대조하고, 어긋난 지점만 다시 시킨다. 이 "위임 → 확인 → 재위임" 반복이 이 스터디가 학기 내내 쓰는 중심 동작이다.

![위임·확인·재위임 루프](/img/세미나/delegation-loop.svg)

1회차에서 다룬 구조를 되짚으면 — AI에 일을 맡기는 것은 질문 한 번이 아니라 루프다. 시키고(위임), 결과를 근거와 대조하고(확인), 어긋난 부분을 지목해 다시 시킨다(재위임). 한 바퀴에 끝나는 경우는 드물고, 끝나지 않는 것이 실패도 아니다. 루프를 돌 줄 아는 사람과 못 도는 사람의 차이가 이후 팀 프로젝트의 차이로 이어진다.

이 회차의 성공 판정은 하나다 — **내 소재가 1회 이상 실제로 돌아감**. 입력을 넣고, AI가 처리하고, 나온 결과를 내 눈으로 확인한 상태. 마지막에는 "얼마나 달라졌나"를 무엇으로 잴지(측정 빈칸)를 확정한다. 결석했다면 아래 재현 가이드만 따라가도 같은 지점에 도달한다.

## 준비

- **소재 카드 + 미니 PRD 5칸** — 차시 2 산출물. 빈칸이 남았으면 스프린트 첫 5분에 채운다. 미니 PRD 5칸 = ①문제 한 줄 ②as-is 실측 계획 ③완성 기준(T/F 1개) ④폐기 조건 ⑤개정 이력. 이 중 1칸과 3칸이 오늘 위임문의 뼈대가 된다.
- **원자료 1건** — 결과가 맞는지 대조할 실물(강의자료·공고 원문·표 등). 이것이 없으면 오늘 만든 것이 맞는지 판정할 방법이 없다. AI의 출력은 그 자체로 진위를 보증하지 않는다 — 판정 기준은 항상 AI 바깥의 내 자료다. 원자료 1건은 준비물이 아니라 검증 장치다.
- **챗봇 로그인 상태(아무거나)** — 특정 도구를 지정하지 않는다. 무료 한도에 걸리면 다른 챗봇으로 갈아타는 것까지 오늘 연습에 포함되기 때문이다. 로그인이 안 되면 사전 설치 가이드의 해당 절부터 처리한다.

## 진행

스프린트는 두 구간이다 — 제작(예: 45분) + 측정 방법 확정(예: 15분). 제작 구간은 강의가 아니라 각자 작업이고, 진행자는 순회하며 막힌 사람에게 말로만 알려준다(화면 조작은 본인이 한다 — 대신 해주면 다음 회차에 같은 지점에서 다시 막힌다).

### 미니 PRD가 위임문이 되는 원리

위임문을 백지에서 짓지 않는다. 미니 PRD 1칸(문제)과 3칸(완성 기준)을 그대로 읽어주듯 넣는 것이 기본형이다.

> "나는 ___할 때마다 ___가 문제다. ___가 되면 완성이다. 이걸 만들어줘."

이 형태가 작동하는 이유 — AI가 산출물을 빗나가게 만드는 원인의 대부분은 "무엇이 완성인지"가 지시문에 없기 때문이다. 완성 기준(T/F 1개)이 문장으로 박혀 있으면, AI도 그 기준을 향해 출력을 조립하고 나도 그 기준으로 결과를 판정할 수 있다. 위임과 검증이 같은 문장을 공유하게 되는 것 — 이것이 차시 2에서 미니 PRD를 먼저 쓴 이유다.

### 확인 — 원자료 대조가 검증의 기본기인 이유

결과가 나오면 그럴듯한지 훑는 것이 아니라, 결과의 한 줄을 골라 원자료에서 같은 내용을 찾는다. 원자료에 없는 문장이 결과에 있으면 그것이 환각이다.

환각은 AI의 실수가 아니라 구조의 귀결이다(1회차에서 다룬 내용) — 언어모델은 "맞는 말"이 아니라 "그럴듯한 다음 말"을 생성한다. 그래서 검증은 선택이 아니라 루프의 고정 단계이고, 검증 기준은 AI에게 물어서가 아니라 내 원자료에서 나와야 한다. AI에게 "이거 맞아?"라고 물으면 그 답도 같은 방식으로 생성된 출력일 뿐이다.

어긋난 지점을 찾으면 전체를 다시 시키지 않는다. **그 부분만 지목해서 다시 시킨다** — "3번 항목은 원자료에 없는 내용이다. 원자료 기준으로 다시 써줘." 지목 재위임은 어긋난 곳이 고쳐질 확률을 높인다 — 단, AI 출력은 매번 조금씩 달라질 수 있으므로 수정본 전체를 다시 원자료와 대조한다(그래서 3단계가 "수정된 결과를 다시 대조"로 끝난다).

### 막힘 유형과 처방의 원리

당일에는 처방표(스프린트 운영 가이드)로 진단하지만, 표를 외우는 것보다 각 처방이 왜 작동하는지를 이해하는 쪽이 오래 남는다. 자주 나오는 막힘의 원리를 풀면 이렇다.

**원하는 형식이 안 나온다 → 결과 예시 1개를 붙여넣는다.** "표로 정리해줘, 이런 느낌으로"라는 말 설명은 해석 여지가 넓다. 원하는 출력의 견본(표 1줄·문항 1개)을 그대로 보여주면 AI는 그 패턴을 이어서 생성한다. 형식은 설명하는 것보다 보여주는 것이 정확하다 — 견본 1개가 형용사 열 개보다 강하다.

**결과가 돌릴 때마다 다르게 나온다 → 기준을 번호 목록으로 고정한다.** 형식(표/목록)·개수(예: 문항 10개)·순서(예: 날짜순) 같은 기준이 문장 속에 흩어져 있으면 매 실행마다 다르게 해석된다. 번호 목록으로 박으면 해석 여지가 줄어 출력이 안정된다. 같은 위임문 = 같은 결과에 가까워지는 것 — 나중에 이 위임문을 재사용 자산으로 만들 때의 전제이기도 하다.

**대화가 길어지자 앞 내용을 잊는다 → 새 대화를 연다.** 챗봇이 기억하는 범위(컨텍스트 윈도)에는 한계가 있고, 긴 대화에서는 초반 지시가 밀려난다. 긴 대화를 고치려 드는 것보다 새 대화의 첫 입력으로 미니 PRD 5칸 요약을 넣고 이어서 시키는 쪽이 확실하다. 여기서도 미니 PRD가 효자다 — 대화가 날아가도 PRD가 있으면 어디서든 다시 시작할 수 있다.

**무료 사용량 한도에 걸린다 → 다른 챗봇으로 갈아탄다.** 미니 PRD가 있으면 도구를 바꿔도 같은 위임문으로 이어진다. 이것이 이 스터디가 특정 도구 사용법 대신 기능 축을 가르치는 이유다 — 도구는 학기 중에도 바뀌지만, 위임문을 만드는 능력은 도구를 갈아타도 그대로 이식된다.

**뭘 시켜야 할지 막막하다(백지) → 미니 PRD 1·3칸을 그대로 넣는다.** 위 기본형 그대로. 백지 상태에서 위임문을 새로 짓는 것은 오늘의 과제가 아니다.

**결과가 맞는지 모르겠다 → 원자료 대조.** 위에서 다뤘다. 로그인·계정 문제는 사전 설치 가이드의 해당 절(학교 구글 계정은 일부 서비스가 막혀 있을 수 있다 → 개인 계정으로 우회), 소재 자체가 과대한 경우는 아래 축소 규칙으로 간다.

### 15분 규칙 — 축소는 실패가 아니라 v2 개정

같은 지점에서 15분 넘게 막히면 더 붙잡는 것이 아니라 소재를 줄인다. 미니 PRD 3칸(완성 기준)을 절반 크기로 다시 쓴다. 예: "강의노트 전체 → 요약+퀴즈 10문항"이 안 돌면 "강의노트 1개 챕터 → 요약만"으로.

이 규칙의 근거 — 오늘의 판정은 "1회 돌아감"이다. 큰 소재를 끌고 가다 0회로 끝나는 것이 가장 나쁜 결과다. 절반 소재라도 돌아가면 다음 주에 범위를 되돌릴 수 있지만, 0회는 되돌릴 것 자체가 없다.

그리고 축소는 폐기가 아니라 **개정**이다. 줄인 내용을 미니 PRD 5칸(개정 이력)에 v2로 적는다 — "AI에 시켰는데 안 된 것 / 바꾼 것". v1으로 끝난 PRD는 위임을 안 해봤다는 뜻이고, v2가 생긴 PRD는 위임 루프를 실제로 돌았다는 증거다. 이 기록이 다음 회차 발표의 "실패 1건" 재료가 된다 — 실패 슬롯이 발표 템플릿에 처음부터 있는 이유다.

### 측정 2종 분기 — 마지막 구간의 논리

돌아가게 만든 다음은 "얼마나 달라졌나"를 잴 방법이다. 분기 질문은 하나 — **"이 작업, 스터디 전에도 하고 있었나?"**

- **예 → 절감형.** 원래 하던 일을 더 짧게 만든 것. 이전의 소요 시간이 실제로 존재하므로 전·후 시간으로 잰다.
- **아니오 → 신규 루틴형.** 원래 안 하던 일을 새로 굴리는 것(예: 주간 공고 브리핑). "전 시간"이라는 것이 애초에 존재하지 않는다 — 존재하지 않는 값과 비교할 수 없으니, 대신 사용 횟수와 지속 주수로 잰다.

![측정 2종 분기 결정 트리](/img/세미나/measure-fork.svg)

분기가 필요한 이유는 이것뿐이다 — 측정값이 존재할 수 없는 유형에 전·후 비교를 강요하면 지어낸 수치가 나온다. 애매하면(하다 말다 했음) 절감형으로 두되, 전 값 = 최근 1회 실측값으로 잡는다. 채운 값은 옆 사람이 읽고 "그 수치 어디서 났어?"에 답이 되는지 확인한다 — 답이 "감이다"면 측정법 칸을 다시 쓴다.

## 재현 가이드

결석자가 혼자 같은 지점에 도달하는 절차. 소요 예: 60분.

**0단계 — 준비물 점검.** 차시 2의 소재 카드·미니 PRD 5칸, 원자료 1건, 챗봇(아무거나) 로그인. 미니 PRD에 빈칸이 있으면 먼저 채운다(장치 10 양식 참조).

**1단계 — 위임문 만들기.** 미니 PRD 1칸(문제)과 3칸(완성 기준)을 아래 틀에 끼운다. 원자료를 붙여넣을 수 있으면 함께 넣는다.

절감형 소재 예문 전문(예: 강의노트 요약·퀴즈):

```
나는 시험 전에 강의노트를 훑을 때마다 양이 많아 정리가 안 되는 게 문제다.
챕터 요약 1페이지와 퀴즈 10문항이 나오면 완성이다.

아래 강의노트 1개 챕터를 기준으로 만들어줘.

[기준]
1. 요약은 목록 형식, 항목 10개 이내
2. 퀴즈는 10문항, 각 문항에 정답 표기
3. 노트에 없는 내용은 넣지 않는다

[붙여넣기: 강의노트 챕터 원문]
```

신규 루틴형 소재 예문 전문(예: 공고 레이더 주간 브리핑):

```
나는 대외활동 공고를 챙겨야 할 때마다 여러 사이트를 도는 게 문제다.
공고 목록을 넣으면 마감순 브리핑 1개가 나오면 완성이다.

아래 공고 목록을 기준으로 만들어줘.

[기준]
1. 표 형식 — 공고명 / 마감일 / 지원 자격 3열
2. 마감 임박순 정렬
3. 목록에 없는 공고는 만들어 넣지 않는다

[붙여넣기: 이번 주 수집한 공고 목록 원문]
```

두 예문의 공통 구조 — 1문장째 = PRD 1칸(문제), 2문장째 = PRD 3칸(완성 기준), [기준] = 형식·개수·순서의 번호 목록, 마지막 = 원자료. 자기 소재로 바꿀 때 이 네 부분만 갈아끼운다.

**2단계 — 실행·확인.** 위임문을 넣고 결과를 받는다. 결과의 한 줄을 골라 원자료에서 같은 내용을 찾는다. 원자료에 없는 문장 = 환각 → 다음 단계 재료.

**3단계 — 재위임 1사이클.** 어긋난 지점을 지목해서 다시 시킨다. 예문:

```
퀴즈 7번은 노트에 없는 내용이다. 노트에 있는 내용만으로 다시 만들어줘.
나머지 문항은 그대로 둔다.
```

전체 재생성이 아니라 지목 수정이라는 점이 핵심이다. 수정된 결과를 다시 원자료와 대조한다 — 이것으로 위임 → 확인 → 재위임 한 바퀴가 끝났다.

**4단계 — 막히면 자가 처방.** 형식이 안 나오면 결과 견본 1개 붙여넣기 / 매번 다르게 나오면 기준을 번호 목록으로 / 대화가 길어져 헛돌면 새 대화 + PRD 요약 재투입 / 한도에 걸리면 다른 챗봇으로 같은 위임문 / 15분 넘게 같은 지점이면 완성 기준을 절반으로 줄이고 PRD 개정 이력에 v2로 기록. 각 처방의 원리는 진행 절 참조.

**5단계 — 측정 빈칸 확정.** 분기 질문("이 작업, 스터디 전에도 하고 있었나?")으로 유형을 판정하고, 해당 양식을 채운다.

절감형 양식 전문:

```
전 = ___분  (잰 날짜: ____ / 없으면 다음 세션 전 재는 날짜: ____)
측정법 = ______________________
  (언제·무엇을 재는지 한 문장. 예: "다음 과제 1건을 손으로 할 때 시작~끝 스톱워치")
```

신규 루틴형 양식 전문:

```
주 ___회 사용 목표  /  지금까지 ___회
기록처 = 주중 폼 (실사용 횟수 칸에 매주 자가보고)
```

채운 값은 미니 PRD 2칸(as-is 실측 계획)에 옮겨 적는다 — 다음 회차 발표 템플릿이 이 값을 그대로 가져간다. 스스로 점검하려면 "그 수치 어디서 났어?"에 한 문장으로 답해본다.

**완료 판정(T/F) — 내 소재 1회 돌아감 + 측정 빈칸 확정.** 두 개가 손에 있으면 이 회차를 재현한 것이다. 자동화(폼 → 시트 → 자동 메일)까지 가보고 싶으면 선택 자료 「자동화 따라 치기」를 이어서 한다 — 필수 아니다.

주중에는 폼에 이번 주 실사용 횟수 1칸을 적는다. 오늘 돌아간 것을 실제로 쓴 횟수만 적는다 — 0회면 0회 그대로. 0회를 부풀리지 않는 것이 측정의 시작이다.

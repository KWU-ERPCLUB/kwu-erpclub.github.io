첫 회차. 진도 없이 방향을 맞추는 60분. 다섯 파트 — AIM 소개 9분 · 커리큘럼 18분 · AIM 웹 12분 · AI 트렌드와 판단 기준 17분 · 마무리 4분. 발표자료 35장은 표지를 눌러 연다. 화면에서 항목을 하나씩 짚는 장(채용 공지·회차 표·협업 룰·경계 대장·마무리)과 신청 목록 체크 장이 있다.

## 다루는 내용

- **AIM 소개** — 채용 전형이 바뀌고 있다(7~9월 SK하이닉스·신한은행·포스코·기아 4건, 대기업 25곳 중 8곳이 AI 활용 경험을 평가에 반영). 문과 직무 공고가 요구하는 것(공고 문구 3 · 숫자 3). 일정 9/14~11/16, 매주 월 18:00~20:00.
- **커리큘럼** — 학습 자동화 2회 → 시험기간 → 팀 프로젝트 4회, 회차마다 그날 끝내는 일 1건. 학습과 자동화가 안 맞는 지점(연구 근거 2건)과 운영자 방식의 빈틈 3곳. 시험 공부와 과제는 도구가 다르다(Gemini·NotebookLM / VS Code + Copilot). 파일을 직접 읽는 도구 네 갈래. 2차 팀 프로젝트는 룰 5칸(저장소·모듈 소유·변경·검수·결정 기록)을 먼저 정한다.
- **AIM 웹** — 이 사이트를 만든 방식(기획 → 구현 → 검수). 인사이트·세미나·프로젝트·워크스페이스의 쓰임. 오늘 신청해 둘 것 6가지.
- **AI 트렌드와 판단 기준** — AI 활용이 세 번 바뀐 흐름, 지금 판을 읽는 축 세 가지, LLM과 LLM 서비스, 프롬프트 → 컨텍스트 → 하네스, 요즘 쓰이는 이름 다섯, 유료와 무료의 같은 점·다른 점, 경계 대장 5칸.

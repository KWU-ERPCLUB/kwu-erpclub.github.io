첫 회차는 진도 없이 방향을 맞추는 60분. 파트 다섯: AIM 소개 9분 · 커리큘럼 18분 · AIM 웹 12분 · AI 트렌드와 판단 기준 17분 · 마무리 4분. 발표자료 35장은 표지를 눌러 연다.

**다음 주까지 준비할 것**

- 회차 2 과목 분석의 재료 4가지: 내 과목 목록 · 과목별 자료 형태(PDF·PPT·녹음) · 시험 방식(객관식·서술·과제) · 매주 반복하는 귀찮은 일 1개
- 신청 6항: 워크스페이스 비밀번호 변경(학번 + 000000으로 로그인 후 내 정보) · Google AI Plus 학생 무료 · GitHub 계정과 Student Pack · Copilot Free 켜기 · VS Code와 Copilot 확장 · NotebookLM 접속 확인. 같은 목록은 워크스페이스 공지에 링크와 함께 게시한다.

## 다루는 내용

- AIM 소개 — 채용 전형이 바뀌고 있다(7~9월 SK하이닉스·신한은행·포스코·기아 4건)
- 채용 조사 — 대기업 25곳 중 8곳이 AI 활용 경험을 평가에 반영
- 문과 직무 공고 — 공고에 반복되는 표현 3개와 숫자 3개
- 일정 — 9/14~11/16, 매주 월 18:00~20:00
- 커리큘럼 — 학습 자동화 2회 → 시험기간 → 팀 프로젝트 4회, 회차마다 그날 끝내는 일 1건
- 학습과 자동화 — 둘이 안 맞는 지점과 운영자 방식의 빈틈 3곳
- 도구 — 시험 공부는 Gemini·NotebookLM, 과제는 VS Code + Copilot
- 파일 접근 — 복사 없이 파일을 직접 읽는 도구 네 갈래
- 팀 프로젝트 — 룰 5칸(저장소·모듈 소유·변경·검수·결정 기록)을 먼저 정한다
- AIM 웹 — 만든 방식(기획 → 구현 → 검수)과 인사이트·세미나·프로젝트·워크스페이스의 쓰임
- 신청 — 오늘 준비해 둘 6가지
- AI 트렌드 — 활용이 세 번 바뀐 흐름과 지금 판을 읽는 축 세 가지
- 구조 3단 — 프롬프트 → 컨텍스트 → 하네스, 유료와 무료의 같은 점과 다른 점
- 판단 기준 — AI가 틀린 지점을 적는 기록표 5칸

최종 목표 = 증명 가능한 일상 활용자

한 학기 뒤 도달 상태 · 4단 순서로 도달

STEP 1 트렌드 파악주간 브리핑·인사이트로 흐름 감지
STEP 2 적용처 선정본인이 실사용자인 반복 작업에서 발굴
STEP 3 기획요구·조건을 브리프로 명세
STEP 4 AI 구현구현·반복은 AI에 위임, 결과는 검수

격차의 원인 = 도구가 아니라 시키는 방식

같은 과제(경영정보 팀과제 발표자료 준비)를 두 방식으로 AI에 요청한 결과 비교 · 전원 챗봇 경험자

방식 A

질문 한 줄만 입력

입력
"과제 발표자료 만들어줘"
결과

뼈대만 있는 일반 목차. 과목·분량·형식 미반영이라 다시 시키는 왕복 반복.

방식 B

브리프 4칸을 채워 입력

브리프 = AI에 주는 작업 지시서. 배경·목표·조건·형식 4칸이 기본형.
입력
배경 = 경영정보 팀과제
목표 = 10분 발표 골격
조건 = 출처 필수 · 표 1개
형식 = 슬라이드 개요 8장
결과

같은 도구·같은 시간에 조건이 반영된 제출용 초안.

판정 = 두 결과 중 그대로 제출할 수 있는 쪽은 어느 것인가 격차를 만든 변수 = 도구 등급이 아니라 브리프의 유무 · 이 브리프 작성법이 차시 2의 내용

GUIDE

허브 사용법

AIM 허브 사이트를 처음 쓰는 사람을 위한 안내. 5분이면 전부 읽는다.

1이 사이트는

AIM(광운대 ERP연구회 산하 MIS·AI 스터디)의 허브다. 두 영역으로 나뉜다.

  • 공개 영역 = 누구나 열람. AI 인사이트, 세미나 기록, 프로젝트, 모집 안내
  • 워크스페이스 = 스터디원 전용(로그인). 일정·공고·기고·내정보

주소 = kwu-erpclub.github.io

2처음 로그인

가입 버튼이 없다. 계정은 운영진이 만들어 준다.

  1. 상단 메뉴 WORKSPACE 클릭
  2. 아이디 = 본인 학번 (숫자만)
  3. 비밀번호 = 초기 비밀번호 000000
첫 로그인 후 내정보 탭 > 비밀번호 변경에서 꼭 바꾼다. 비밀번호를 잊으면 운영진에게 초기화를 요청한다.

3홈 = 일정 한눈에

로그인하면 홈이 먼저 뜬다.

  • 캘린더 = 스터디 세션, 공고 마감, 학사일정이 한 달 단위로 표시. 날짜의 항목을 누르면 세부 팝업
  • 다가오는 업무 = 우측 상단. 챙겨야 할 핵심 일정만 추려서 표시
  • 공지 = 우측 하단. 운영진이 올린 안내

4로드맵 = 이번 학기 흐름

1기 전체 일정이 회차 단위로 나열된다. 지금 어디까지 왔는지, 다음 세션이 무엇인지 여기서 확인한다.

  • 회차를 누르면 세부 내용과 자료가 열린다
  • 자물쇠 표시 = 공개일 전. 세션이 진행되면 자동으로 열린다

5공고 = 공모전·채용·자격증 보드

운영진이 골라 올리는 외부 공고 모음. 모든 공고에 "왜 볼만한가" 한 줄이 붙는다.

  • 상단 필터로 분류별 열람(공모전, 채용, 자격증, 대외활동, 학사일정)
  • 카드의 ★을 누르면 관심 공고로 저장(내정보 탭에 모임)
  • 필터의 캘린더에 등록을 켜면 그 분류의 마감일이 홈 캘린더에 뜬다

6인사이트 기고 = 주 1건 상시 과제

관심 소재를 AI로 정리해 한 편씩 기고한다. 두 방법 중 하나를 고른다.

  • 사이트 서식으로 게재 = 제공되는 프롬프트를 복사해 본인 AI에 넣고, 나온 초안을 붙여넣으면 폼이 채워진다. 디자인은 사이트가 맡는다
  • 본인이 디자인까지 = HTML 한 벌을 직접 만들어 붙여넣는다. 게재 시 그 모습 그대로

제출하면 운영진 승인 후 공개 인사이트 페이지에 게재된다.

7내정보 = 내 것 모아보기

  • 내 북마크 = 인사이트에서 북마크한 글
  • 관심 공고 = 공고에서 ★ 누른 것
  • 캘린더에 등록한 분류 = 홈 캘린더에 띄울 공고 분류 관리
  • 프로필 수정 · 비밀번호 변경 = 하단 접힘 메뉴

8인사이트 읽기

로그인 없이도 읽을 수 있다. 로그인 상태면 글 상세에서 좋아요와 북마크를 누를 수 있다.

  • 카드의 빨간 N = 최근 7일 내 게재 + 아직 안 읽은 글
  • 필터 칩으로 시리즈(주간 AI 트렌드 등)만 골라 볼 수 있다

9폰에서 앱처럼 쓰기

홈 화면에 추가하면 앱처럼 전체 화면으로 열린다. 앱스토어 설치와 비용이 없다.

  • 아이폰 = 사파리로 접속하고 공유 버튼에서 홈 화면에 추가 (아이폰의 크롬 앱에서는 안 됨)
  • 갤럭시(크롬) = 우상단 ⋮ 메뉴에서 홈 화면에 추가 (기기에 따라 "앱 설치")
  • 갤럭시(삼성 인터넷) = 하단 ☰ 메뉴에서 현재 페이지 추가, 홈 화면 선택

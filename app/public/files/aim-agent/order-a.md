# 발주서 A · 기회 공고 수집 에이전트

AIM 허브 워크스페이스 「공고」 탭를 매주 채울 에이전트를 발주한다. 받는 것은 완성된 에이전트 하나다. 만드는 방법은 자유다.

## 1. 배경

2026-10-24 기준 허브 「공고」 탭에는 36건이 있다. 그중 27건은 마감이 지났고 8건은 마감일이 없다. 공고를 모으던 자동 실행이 멈춰서 생긴 일이다.

이 에이전트는 공고 페이지를 읽고 공고 탭에 올릴지 판정한 뒤 공고 탭 형식으로 넘긴다. 합격 기준을 통과하면 운영진이 매주 자동 실행에 넣는다.

## 2. 발주처 요청문

> 공고 탭 담당입니다. 이번 주부터 공고 고르는 일을 맡기려고 합니다. 아래만 지켜 주세요.
>
> 1. 설정에 적은 관심 분야 공고만 올려 주세요. 개발자를 뽑는 자리, 코딩을 가르치는 과정, 그림 · 영상 같은 작품을 내는 공모전은 빼 주세요.
> 2. 우리 학생이 지원할 수 없는 공고는 빼 주세요.
> 3. 학생이 돈을 내야 하는 건 빼 주세요.
> 4. 지방까지 가야 하는 건 빼 주세요.
> 5. 기준일부터 3일 안에 마감되거나 이미 마감된 건 빼 주세요.
> 6. 애매하면 마음대로 정하지 말고 물어봐 주세요. 무엇을 확인하면 정해지는지 한 줄로 적어 주시면 됩니다.
> 7. 공고에 없는 내용은 채워 넣지 마세요. 페이지가 잘리거나 깨져서 들어오면 그렇다고 알려 주세요.

요청문만으로 정해지지 않는 부분은 운영진에게 묻는다. ~10/30까지 받은 질문과 답은 11/1에 모두 공개한다. 검수의 정답은 요청문과 공개 답변으로 정해진다.

## 3. 입력

사용자가 기준일과 공고 여러 건을 붙여 넣는다. 정리된 요약일 때도 있다. 공고 페이지를 통째로 복사한 원문일 때도 있다.

설정은 에이전트 맨 위에 둔다. 설정만 바꾸면 다른 사람도 그대로 쓸 수 있어야 한다.

```
[설정]
관심 분야: (예: 금융 · 경제 · 핀테크)
받을 공고 종류: 공모전 · 채용 · 대외활동 중 고름
학생: 서울 소재 대학 경영학부 학부생 · 코딩은 하지 않음
학년: (예: 3학년 재학) · 졸업 예정: (예: 2028년 2월)
지역: 서울 · 경기 · 인천
```

## 4. 출력 형식

**① 판정표** (입력한 공고 전부)

| 번호 | 제목 | 판정 | 요청 번호 | 근거(원문 그대로) | 확인 질문 |
|---|---|---|---|---|---|

| 판정 | 언제 |
|---|---|
| `채택` | 공고 탭에 올림 |
| `제외` | 요청 1~5 중 하나에 확실히 해당. 요청 번호 칸에 번호 |
| `확인 요청` | 요청문으로 정해지지 않음. 확인 질문 칸에 판정을 가르는 질문 한 줄 |
| `입력 오류` | 판정에 꼭 필요한 부분이 잘렸거나 깨져 읽을 수 없음 |

**② 허브 형식** (채택한 공고만, JSON 배열. JSON = 칸 이름과 값을 정해진 모양으로 적는 데이터 형식)

```json
[
  {
    "키": "linkareer-351221",
    "제목": "원문 제목 그대로",
    "종류": "공모전",
    "분류": "학회대학",
    "주최": "원문의 주최 기관",
    "출처": "링커리어",
    "url": "https://linkareer.com/activity/351221",
    "접수시작": "2026-09-01",
    "접수마감": "2026-11-16",
    "시험일": null,
    "코멘트": null,
    "고정": false
  }
]
```

| 칸 | 값 |
|---|---|
| 키 | `출처 영문 이름-공고 번호`. 링커리어면 링크 끝 숫자(예: `linkareer-351221`) |
| 종류 | 해커톤 · 경진대회 · 아이디어 공모 = `공모전` · 인턴 · 신입 채용 = `채용` · 서포터즈 · 교육생 · 캠프 모집 = `대외활동` |
| 분류 | 공모전 = `정부공공` · `기업` · `학회대학` · `기타` / 채용 = `대기업` · `중견중소` · `공기업공공` · `스타트업` · `기타` / 대외활동 = `기타` |
| 출처 | `링커리어` · `잡코리아` · `사람인` 중 하나 |
| 날짜 | `YYYY-MM-DD`. 원문에 없으면 `null`(값이 없다는 표시. 빈 문자열이 아님) |
| 시험일 · 코멘트 · 고정 | 항상 `null` · `null` · `false` |

**③ 실행 보고**

```
기준일: YYYY-MM-DD
본 공고: N건 / 채택 N · 제외 N · 확인 요청 N · 입력 오류 N
제외 요청별: 1번 N · 2번 N · 3번 N · 4번 N · 5번 N
값이 서로 다르게 적힌 곳: (공고 번호 · 칸 · 두 값)
비운 값: (공고 번호 · 칸 · 이유)
```

채택이 0건이면 첫 줄에 `채택 0건`, 입력 오류가 있으면 첫 줄에 `입력 오류 N건`이라고 쓴다.

## 5. 제출 형식

- 에이전트 1개 = 텍스트 파일 1개(.md 또는 .txt), 5,000자 이내
- 새 대화창에 그대로 붙여 넣고 공고를 넣으면 바로 실행되어야 한다. 특정 서비스의 기능(메모리, 업로드한 지식 파일 등)에 기대지 않는다
- 맨 위에 3절 설정 블록. 처음 쓰는 사람이 무엇을 붙여 넣으면 되는지 지시문 안에 적혀 있어야 한다
- 워크스페이스 과제 탭에 낸다

## 6. 합격 기준

운영진이 비공개 테스트 세트(공고 10건 안팎)로 검수한다. 실행 = Claude Code 새 세션 3회 + 다른 회사 AI 새 대화 1회. 검수 설정은 아래와 같다.

```
관심 분야: 경영정보시스템(MIS) · ERP · 디지털전환(DX) · 데이터 · AI 활용
받을 공고 종류: 공모전 · 채용 · 대외활동
학생: 서울 소재 대학 경영학부 학부생 · 코딩은 하지 않음
학년: 3학년 재학 · 졸업 예정: 2028년 2월
지역: 서울 · 경기 · 인천
```

| 항목 | 합격선 | 등급 |
|---|---|---|
| 지어내기(근거 칸 포함) | 0건 | 치명 |
| 깨진 입력 | 전부 `입력 오류` | 치명 |
| 허브 형식 | 전부 4절 ②와 일치(문법 · 칸 이름 · 값 목록 · 날짜 모양) | 치명 |
| 판정표 · 실행 보고 형식 | 전부 4절 ① · ③과 일치 | 중대 |
| 정확도 | 3회 평균 90% 이상 | 중대 |
| 정리되지 않은 원문 · 애매한 공고 · 깨진 입력에서의 정확도 | 3회 평균 80% 이상 | 중대 |
| 일관성 | 3회 모두 정답인 공고 90% 이상 | 중대 |
| 다른 회사 AI | 치명 0건 · 정확도 80% 이상 | 중대 |

- 1건 정답 = 판정 + (제외면 요청 번호) + (채택이면 종류 · 접수마감) + (확인 요청이면 질문이 판정을 가르는 정보를 가리킴)
- 결과는 셋 중 하나다. 치명 결함이 하나라도 있으면 불합격, 치명은 없고 중대 결함만 있으면 조건부(다시 제출할 때 고치면 합격), 둘 다 없으면 합격. 11/6 1차 결과를 보고 11/9에 한 번 다시 낼 수 있고, 최종 판정은 다시 낸 파일로 한다.

## 7. 입력 예시와 기대 결과

입력 예시 = `발주서-A-입력예시.md`(공고 5건). 아래 설정에서의 기대 결과다.

```
관심 분야: 금융 · 경제 · 핀테크
받을 공고 종류: 공모전 · 채용 · 대외활동
학생: 서울 소재 대학 경영학부 학부생 · 코딩은 하지 않음
학년: 3학년 재학 · 졸업 예정: 2028년 2월
지역: 서울 · 경기 · 인천
```

| 번호 | 기대 결과 | 이유 |
|---|---|---|
| 1 | 제외 · 3번 | 교육비 15만원 |
| 2 | 제외 · 5번 | 마감 2026-10-26, 기준일로부터 2일 |
| 3 | 채택 · 공모전 · 접수마감 2026-11-16 | 금융 + AI 활용 보고서 · 대학 재학생 · 온라인 · 참가비 없음 |
| 4 | 확인 요청 | 「자유 주제, AI금융 서비스 우대」라 금융 분야 공고로 볼지 요청문만으로 정해지지 않음 |
| 5 | 입력 오류 | 제목이 없고 날짜가 잘림 |

4번은 11/1 공개 답변에 따라 기대 결과가 바뀔 수 있다.

## 8. 일정

| 날짜 | 내용 |
|---|---|
| 10/26 | 발주 |
| ~10/30 | 질문 받기 |
| 11/1 | 질문과 답 공개 |
| 11/2 | 제출 |
| ~11/6 | 검수 결과 전달 |
| 11/9 | 다시 제출(1회) |
| 11/16 | 합격 에이전트 자동 실행 등록 |

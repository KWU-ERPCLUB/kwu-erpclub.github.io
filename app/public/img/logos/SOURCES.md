# 로고 이미지 출처

기사가 다루는 **주체(기업·제품·기관)** 를 가리키는 식별 표시로만 쓴다(보도·논평 목적의 명목적 사용).
상표권은 각 소유자에게 있고, 이 사이트는 후원·제휴 관계를 주장하지 않는다.

## 현행 18종

claude · anthropic · openai · codex(png) · gemini · meta · mistral · perplexity · huggingface ·
github · copilot · notion · ollama · langchain · n8n · zapier · colab · kaggle — 각 사 공식 브랜드 자산·Simple Icons.
사용 조건은 위와 같다(주체 식별 용도).

## 추가할 때

1. 기사가 그 주체를 실제로 다룰 때만 받는다(장식용 배정 금지 — 규칙 = 루트 `CONTRIBUTING.md`).
2. 파일명 = 소문자 슬러그(`.svg` 우선, 벡터 없으면 `.png`).
3. 이 표에 파일·주체·원본 URL·라이선스를 한 줄 추가한다.

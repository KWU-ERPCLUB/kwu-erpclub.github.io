# ERP연구회 사이트 (site)

## 목적
광운대학교 경영학부 AIM(AI×MIS) 스터디의 **허브**. 주 사용자 = 스터디원(반복 방문 작업공간·자료창) /
부 = 멤버가 외부에 성과를 보여줄 때의 증빙면. 심장박동 = 정보 공유 — **AI 인사이트(이슈 아카이브) → 세미나(선별 실습)** 파이프라인.
카피 상위 기준 = `../docs/정체성-북극성.md`(웹 비표기 내부 북극성). 사이트 자체가 스터디 방식(AI 협업·git·무료 배포)의 증거물.
